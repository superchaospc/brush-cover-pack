# 社媒标题写法（抖音、小红书不限流版）

每套封面附一个 `社媒标题.txt`，各平台一段，开头写清数据来源，以及主标题里的数字是怎么来的。

## 不能写

- 收入承诺和赚钱噱头：月入、年入、赚了X万、副业、躺赚、普通人也能、人人都能做
- 境外平台的名字：YouTube、TikTok、Instagram、油管、ins、tk（话题标签里也不行）
- 货币符号，以及「到手多少」这类收入数字
- 引导去站外：「去××关注我」「完整版在××」

## 可以写

- 可核实的增长数据：播放、粉丝、改版前后对比，例如「播放涨了34倍」「半年涨粉10万」
- 个案复盘的口吻：「一位××的改版复盘」「拆解他改了什么」
- 「内容出海」「外网」「海外观众」

## 模板

```
<博主> 频道拆解 · 社媒标题（按抖音、小红书规则写）
（数据：<报告名>，截至 <日期>。「<主标题数字>」= <口径>，来自 <来源>）

抖音
<身份>，<经历/反差>，<增长数据>
#内容出海 #自媒体运营 #频道拆解 #vlog

小红书（标题，20 字以内）
<白字二>，<主标题>
小红书（话题）
#内容出海 #自媒体运营 #vlog拍摄 #频道拆解

视频号
<反差句>：一位<身份>的改版复盘

B站
【频道拆解】<身份><白字二>，<主标题>

公众号
<身份>，<一句话变化>，<增长数据>

YouTube
<身份><白字二>，<主标题>｜<系列名>

视频简介（抖音/小红书也可用）
<两三句经历> <改了什么> <数据>。这期是个案复盘，数据来自公开页面，不代表每个人都能复制同样的结果。
```

## 示例（Paul in China）

```
抖音
不会英语的货拉拉司机，摸索大半年换了一套打法，播放涨了34倍
#内容出海 #自媒体运营 #频道拆解 #vlog #AI配音

小红书（标题）
不会英语做内容出海，改版后播放涨34倍
```
