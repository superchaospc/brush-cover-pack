## 共同视觉语言

1. **强层级**：小号黄色笔刷品牌条 → 两层白色说明 → 最大的黄色主标题。通常讲清“谁／做什么／最值得点开的结果或问题”。四段语义可在竖版多行排，不强求物理四行。
2. **字形**：极粗、略倾斜的中文笔刷字，有飞白和粗糙边缘，但字面密实；不是普通细黑体，不为了纹理牺牲识字。
3. **承托文字**：大面积黑色斜向笔刷遮罩，边缘少量黄色飞溅。它负责隔开复杂背景，让白黄文字形成清楚对比。
4. **颜色**：黑／黄／白为主，人物和环境偏暖金色；红橙只强调少数关键词或数字，加白色描边。不要把每个重点都变红，不把肤色染成橙红。
5. **人物和光线**：写实、清晰、自然比例，背景柔化，有暖色边缘光。脸与主标题形成两个视觉焦点；眼镜不变成绿眼睛。
6. **场景有意义**：驾驶室、工厂、居家、夜街与本期内容对应。箭头、手机或电脑只是辅助；不能机械每张都放，不借此编造设备、职业或真实拍摄现场。
7. **不是 PPT 风格**：封面追求缩略图级可读和一个明确看点；不要把报告的米色卡片、多列表格、长说明搬到封面。

## 使用方法

- 下次需要此风格时先打开相关的 16:9 与目标画幅各一张，明确要借用的是字形、层级、色调还是构图。
- 将本期文案、数字出处、人物要求单独确定；生成提示词分“风格参考”“身份参考”“本期准确文字”“目标比例”“禁止继承的旧元素”。
- 共同内容变化需同步全部交付比例；只修单幅裁切时不重做无关版本。
- 逐字检查中文、数字和品牌，再看完整脸部、安全边距、实际宽高比；记录实际未解决偏差，不因提示词写了百分比就声称达标。
- 修改旧图使用当前环境允许的图像编辑工具。旧文档中的 Python 拼接、修脸、停进程和导出命令不自动获准执行。
